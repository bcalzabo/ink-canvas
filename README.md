# ink-canvas
Ink Canvas for the BOOX Tab X C
A free, native color drawing app for the Onyx BOOX Tab X C. It draws with the fast, low-latency firmware ink in color, has layers, a 4,096-color picker with an eyedropper, shapes, image import, zoom to 300%, a paint-mixing Blend Mode, and PNG/JPG export.

Download
Get the latest inkcanvas.apk and the user guide (PDF) from the Releases page.

Install
Copy inkcanvas.apk to the tablet.
Tap it in the BOOX file manager.
If Android asks, allow installs from this source, then tap Install.
Full steps are in the user guide.

Status
This is a beta, tested only on the Tab X C with firmware 4.2 (rel_05122). Colors while the pen is down are close to the picked color but not always exact; the finished stroke is exact. See the guide's Limitations section.

Found a bug? Open an issue and include your firmware version and the steps to reproduce it.

This repository only hosts downloads. The app's source code is not public.
